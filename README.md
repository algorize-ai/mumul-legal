## 현재 문서 상태

문서 식별자, 공고일과 시행일은 `2026-09-16`으로 통일한다. 본문은 광고가 포함된 정식 서비스의 정책을 이용자용 문장으로 작성한다. 문구 확정과 실제 기능 활성화, 배포 및 이용자 동의 이력은 구분하여 확인한다.

사용자 확인에 따라 배포 테스트용 과거 문서와 중복 초안은 정리했다. 과거 게시본은 Git 커밋 `bef2daf`에 보존돼 있다. 현재 페이지와 식별자별 사본은 permalink를 제외한 본문과 메타데이터가 같아야 한다.

공개 본문에 문서 식별자를 별도로 표시할 필요는 없다. `policy_version`과 서버 동의 기록의 버전은 별개로 관리하며, 이 저장소의 변경만으로 서버 데이터가 갱신되지는 않는다.

## 문서 관리 및 운영 확인 사항

- 공개 본문에는 이용자에게 적용되는 정책을 기재하고, 코드 설정과 운영 점검 항목은 이 README에서 관리한다.
- 이용약관의 일반 AI 이용 설명에는 특정 업체를 고정하지 않는다. 실제 업체와 전송 항목·국가·목적·보유기간·거부 절차는 개인정보처리방침의 표에서 관리하며, 업체 변경 시 연결된 설명과 필요한 안내를 함께 갱신한다.
- OpenAI의 학습 활용 조건, 응답 저장 설정 및 오용 방지 기록을 구분한다. DeepSeek는 공개 약관의 조건을 요약하고 공식 약관을 연결하며, 실제 학습 여부·사용 거부 적용 여부·보유기간을 추정하지 않는다.
- Vercel 자체의 정보 처리와 AI 제공사의 정보 처리를 구분한다. 공개 자료에서 확인되지 않은 보유기간이나 비공개 계정·계약 조건을 확인된 사실로 기재하지 않는다.
- 광고는 Google AdMob 배너·보상형 광고를 제공하는 정책으로 작성한다. 추가 미디에이션과 Firebase Analytics는 사용하지 않으며, 구체적인 보상과 시청 조건은 광고 표시 전에 앱에서 안내한다. 미사용 도구 목록과 광고 요청 상태·안내창 설정 등 구현 설명은 공개 본문에 나열하지 않는다.
- 실제 광고 수령자·연락처·처리 국가·항목·목적·보유기간과 법적 근거, 동의·거부·철회 절차는 광고 계약·계정·파트너 설정과 대조한다. 공개 본문의 일반 설명만으로 구체적인 고지가 완료되었다고 판단하지 않는다.
- 앱 내 익명 이용정보 삭제 요청과 soft delete는 구현되어 있다. 연결 데이터의 물리 삭제와 장기 미사용 계정 정리는 고지한 정책에 맞춰 후속 구현·검증한다. 기존 삭제 범위와 보관기간은 유지한다.
- 학습 분석·품질 평가·기능 개선 목적의 기재와 별도로, 식별 가능한 원문을 기능 개선에 이용하는 법적 근거와 보유기간을 확인한다. 법령상 보존·분쟁 대응·순환 백업의 대상, 근거 및 종료 기준도 별도로 확인한다.
- Expo와 Sentry의 신규 고지는 이번 수정에서 보류한다. 보류를 고지 불필요성이나 실제 전송 여부의 검증 완료로 취급하지 않는다.
- 서버 필수 약관 버전과 문서 URL, 앱의 동의 안내를 일치시킨다. 기존 동의 기록을 일괄 덮어쓰지 않는다.
- 메인 페이지, 문서 목록, 두 본문과 사본, 국외이전·삭제 anchor, 모바일 표와 키보드 포커스를 확인한다.

## 배포

GitHub Pages의 **Deploy from a branch** 방식으로 `main` 브랜치의 저장소 루트를 게시한다. Pages가 지원하는 Jekyll로 Markdown을 HTML로 변환한다. README는 `_config.yml`의 exclude 설정으로 사이트 게시 대상에서 제외한다. 공개 Git 저장소 자체에서 README 접근을 차단하는 설정은 아니다.

문구 확정이나 버전 정리만으로 실제 기능 구현, 법적·운영적 확인 또는 배포가 완료되었다고 판단하지 않는다. 실제 배포 후 current URL, 사본 URL, 두 anchor와 HTTPS를 확인한다.
